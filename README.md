# ftir-toolkit

[**English**](README.en.md) | 中文

面向中红外光谱（4000–400 cm⁻¹）的**辅助判读工具集**。它把三件常被含糊处理的事做成可复核的输出：谱图是否可用于分析、谱带可能对应哪些官能团、样品与对照是否一致；同时把每一条判断的不确定性与依据一并写出。

工具不输出化合物身份，不做含量测定，不判定晶型。它给出的是**可追溯的归属假设**，供人复核，而非替代人。

## 能力概览

| 层次 | 回答的问题 | 命令 | 输出 |
|---|---|---|---|
| 质量控制 | 这张谱能用吗 | `check` | 合格 / 需注意 / 不可用，附逐项判据 |
| 归属假设 | 有哪些官能团 | `read` | 峰表（亚像素峰位、不对称度、可信度、竞争归属）+ 结论段 + 交叉验证建议 |
| 谱图比对 | 与对照是否一致 | `match` | 一致 / 需复核 / 不一致，含整体位移估计、四类判据分解与场景诊断 |
| 研究分析 | 系列差异、重叠带拆分 | `single` `compare` `detail` `series` `deconv` | 指标表、趋势、组分占比 |

支持两列文本（`.txt` / `.csv` / `.tsv`）与带 `##` 头的仪器导出文件；自动识别 `%T` 与吸光度，透射谱自动转换为吸光度。

## 设计原则

**一、结论与不确定度同时给出。** 每个峰带可信度，每条结论标注证据条数，每份报告附六条固定声明。

**二、只报告可复核的量。** 峰位、半高宽、面积比、相关系数均可由原始数据复算；不报告无法复算的"匹配度评分"。

**三、不越过方法的能力边界。** 不判定晶型（需 XRD）、不判定分子量（需 MS）、不判定连接方式（需 NMR）。

**四、阈值有出处。** 峰位偏差 ±5 cm⁻¹ 引自药典 [S4]；信噪比 < 3 不作定性依据引自 GB/T 6040 [S5]；相关系数阈值标注为经验值，并要求使用方按专属性验证。

## 快速开始

```bash
python ftir.py check sample.txt          # 谱图是否可用
python ftir.py read  sample.txt          # 官能团归属假设
python ftir.py match sample.txt ref.txt  # 与对照谱比对
```

以下为**构造数据**的输出示例，仅用于说明格式，不对应任何真实样品：

```
=== 谱图解析：示例（构造数据）===
  峰位   强度  峰形  FWHM  可信度  参考归属
  2960    强   尖峰    22     高    饱和 C-H 伸缩（烷基）
  1738    强   尖峰    18     高    酯 C=O 伸缩
  1240    强   尖峰    26     高    C-O-C / C-O 伸缩
  1160    中   尖峰    24     中    C-O-C / C-O 伸缩
   720    中   尖峰    20     中    芳环 C-H 面外弯曲

【结论】
1738 cm⁻¹ 羰基与 1240 cm⁻¹ 强 C-O 共同出现，支持存在酯；2960 cm⁻¹ 为饱和 C-H 伸缩，提示可能含烷基（单条谱带，需复核）。
综合判断：支持存在酯（多条独立谱带）；提示可能含烷基（需复核）。以上为假设，不构成结构确证。
```

报告同时写入 `output/`：`*_read.md`（可粘贴的报告）与 `*_read.png`（峰位标注图，颜色区分为高 / 中 / 低可信）。

## 命令参考

| 命令 | 用途 | 关键参数 |
|---|---|---|
| `check` | 谱图质量体检 | `--smooth` |
| `read` | 归属假设 + 交叉验证建议 | `--peaks` `--lookup/--no-lookup` |
| `match` | 与对照谱比对（位移校正 + 原始/导数双判据） | `--threshold`（0.98）`--deriv-threshold`（0.95）`--max-shift`（15）`--no-align` |
| `single` | 单谱峰表 + 标注图 | `--peaks` `--prominence` |
| `compare` | 多样品峰位对照 | `--labels` |
| `detail` | O-H 重心/半高宽、C=O 二阶导峰位、COO⁻ 分裂、面积比 | `--labels` |
| `series` | 指标随参数变化的趋势与精确置换检验 | `--radii` `--labels` |
| `deconv` | 重叠带伪 Voigt 拟合 | `--region` `--centers` `--model` `--max-peaks` |

通用参数：`--outdir`（默认 `output`）、`--smooth`（默认 9）、`--subtract` / `--sub-factor`（参考谱扣除）、`--json`（机器可读输出）。

## 输出结构

`read` 的 Markdown 报告固定包含六节：

1. **峰表** —— 峰位、强度、峰形、FWHM、可信度、参考归属
2. **结论** —— 逐条证据句 + 综合判断（支持 / 提示两级）
3. **需复核的归属** —— 中低可信峰及其降级原因、竞争归属
4. **交叉验证建议** —— 按识别到的基团给出正交手段
5. **参考谱库入口** —— NIST WebBook、SDBS、PubChem、Coblentz
6. **可信度声明** —— 六条固定声明，含规则法假阳性率

## 判定逻辑

### 峰级可信度

三项加分、四项减分，落点为高（≥2）、中（0–1）、低（≤−1）：

| 方向 | 条件 |
|---|---|
| +1 | 峰位落在参考区间中心 60% 以内 |
| +1 | 相对强度 ≥ 50% |
| −1 | 相对强度 < 20% |
| −1 | 峰不对称（左右半宽比 ≥ 1.30）且较宽一侧二阶导存在肩峰 |
| −1 | FWHM ≥ 80 cm⁻¹ 但未检出肩峰（可能为多峰叠加） |
| −1 | 位于 3200–3600 或 1600–1670 且检出吸潮水 |
| −1 | 信噪比 < 10 |

区间边界、弱峰、宽包、水峰重叠、竞争归属均在报告中逐条说明理由。

### 官能团级判定

单条谱带不足以支持归属，采用**双证据规则**：

| 官能团 | 必需的独立证据 |
|---|---|
| 羧酸盐 | 反对称带（1560–1520）+ 对称带（1445–1395），且 Δν = 70–180 cm⁻¹ |
| 酰胺 | 羰基带（1690–1630）+ N-H 弯曲（1520–1495）或 C-N（1370–1290） |
| 酯 | 羰基带（1760–1735）+ 1180–1000 区间强 C-O（相对强度 ≥ 30%） |
| 羧酸 | 羰基带（1735–1690）+ 极宽 O-H（FWHM ≥ 150） |
| 芳环 | 骨架带（1630–1560）+ 面外弯曲（900–700） |
| 含氟 | 仅单带可用，故恒为「提示」级 |
| 烷基 | 仅在无 O-H / N-H 主张时给出「提示」级 |

满足双证据记为「支持」，单证据记为「提示（需复核）」；谱图质量不达标时不出结论。

### 谱图比对

比对分三步，先定位差异来源，再决定判据，而不是把几个数字硬拼成一个结论。

**第一步：整体位移估计。** 在一阶导谱上于 ±15 cm⁻¹ 内网格搜索（步长 0.25 cm⁻¹），寻找使相关最大的整体平移。只有增益 ≥ 0.03 且极值不触界时才采用——触界说明两谱差异过大，此时不校正。

**第二步：分项计算。** 原始谱相关 r、校正前一阶导相关 r′、校正后 r′ₐ、二阶导相关 r″、校正前后峰位偏差与残差、差异带。位置判据排除 FWHM > 100 cm⁻¹ 的宽包，因为其峰顶由基线决定而非化学环境。

**第三步：按场景给结论。**

| 场景 | 特征 | 处理 |
|---|---|---|
| 系统性波数偏移 | 校正后 r′ 明显恢复、残差收窄 | 判「需复核」，建议波数校准后复测 |
| 成分/结构不同 | 校正后 r′ 仍低、差异带集中 | 判「不一致」 |
| 基线或制样差异 | 导数谱一致而原始谱偏低 | 判「一致」或「需复核」，建议扣空白复评 |
| 临界或相互矛盾 | 判据不同向 | 判「需复核」，不强行给结论 |

**为什么需要位移校正。** 仪器校准状态不同会让两条谱整体错开几 cm⁻¹，这时原始相关和一阶导相关都会下降，但物质本身相同。若不先分离这一项，就会把「仪器漂移」误判成「物质不同」。反过来，两个同族化合物可能因宽包相似而 r 高达 0.99，求导后差异才显现 [S20]。

**判定仍带边界。** 即使判「一致」，输出也会固定附上：*在本方法及当前阈值下未发现显著差异；不等同于化合物身份确证。*「需复核」与「不一致」各有对应的边界说明，不留给读者自行解读。

实测（同一组真实谱）：整体平移 3 cm⁻¹ 后，原始 r = 0.992 仍过阈值，但一阶导 r′ = 0.927 并检出 −3.00 cm⁻¹ 位移，判定降为「需复核」；同族样品 r = 0.996、r′ = 0.995、残差 1.9 cm⁻¹，判「一致」；不同化合物 r = 0.893、r′ = 0.579，判「不一致」。阈值 0.98 / 0.95 为经验值，正式检验应按药典要求预设并做专属性验证 [S4]。

### 参数敏感性

单次计算给出的 FWHM 或面积比，有相当一部分由平滑窗口与基线强度决定，而不是由样品决定。因此 `read` 与 `detail` 默认在三组参数下重算（平滑 7 / 9 / 11，基线 λ 1×10⁵ / 1×10⁶）：

- 峰位在 1.5 cm⁻¹ 内一致、且三组都出现的峰，标记为「稳定」
- 只在部分参数下出现的峰，标记「部分出现」或「疑似伪峰」
- 区间外的峰单独标注「区间外」，不与已归属峰混为一谈
- `detail` 输出每个指标的**跨参数范围与相对波动**，例如 O-H FWHM 主值 28.5、范围 28.2–33.3（±18%），而 Δν 波动 0%，可放心引用

相对波动 > 10% 的指标不宜逐位引用，只宜作趋势比较。`--no-sensitivity` 可关闭（会快约 3 倍）。

## 方法学参数

| 环节 | 方法 | 参数 |
|---|---|---|
| 吸光度转换 | A = −lg(T/100) | 透射率下限裁剪 0.5% |
| 基线校正 | 非对称最小二乘（ALS） | λ = 1×10⁵，p = 0.001，12 次迭代 |
| 平滑 | Savitzky–Golay | 9 点 3 阶 |
| 挑峰 | 局部极大 + prominence 阈值 | 0.02 × 动态范围，最小间隔 3 点 |
| 峰位定位 | 三点抛物线顶点插值 | 栅格 2 cm⁻¹；插值后约 0.1 cm⁻¹。顶点非凹、偏移超过半个点时退回栅格值 |
| 半高宽 | `peak_widths`，rel_height = 0.5 | — |
| 峰不对称度 | 左右半高宽之比 | 仅在 FWHM 12–100 cm⁻¹ 范围内给出；更窄测点不足，更宽则为多带包络 |
| 肩峰判定 | 不对称比 ≥ 1.30 且该侧二阶导存在局部极大 | 搜索半径 45 cm⁻¹，prominence ≥ 该侧最大值 4% |
| 二阶导数 | SG 二次导数取负 | 15 点 3 阶，Δ = 2 cm⁻¹ |
| 导数相关 | SG 一阶/二阶导数后取 Pearson | 15 点 3 阶；二阶导对噪声敏感，列作参考项 |
| 位移估计 | 导数谱网格搜索 + 抛物线细化 | ±15 cm⁻¹，步长 0.25 cm⁻¹；增益 ≥ 0.03 且不触界才采用 |
| 参数敏感性 | 三组参数重算并比对峰位 | 平滑 7 / 9 / 11，基线 λ 1×10⁵ / 1×10⁶；位置容差 1.5 cm⁻¹ |
| 分峰拟合 | 伪 Voigt（共享 η），有界最小二乘 | 峰位约束 ±25 cm⁻¹，FWHM 4–120 cm⁻¹，峰高 ≥ 0 |
| 参考谱扣除 | 原始吸光度相减后重做基线 | `auto` 在参考谱信号区用最小二乘定标 |
| 相似度 | Pearson 相关系数 | 全谱与 ≤1500 cm⁻¹ 分别计算 |
| 趋势检验 | Spearman 秩相关 + 精确置换检验 | n ≤ 8 时枚举全部排列 |

## 不确定性的来源与依据

| 来源 | 影响 | 依据 |
|---|---|---|
| 规则法归属 | 文献报告假阳性率约 19%，假阴性约 1% | [S6] |
| 区间表反向使用 | 缺峰不能否定基团存在 | [S7] |
| ATR 与透射差异 | 峰位红移、峰形畸变，强峰更明显 | [S8][S9] |
| 分峰非唯一 | 增加组分总能改善残差，低残差不代表真实 | [S10][S11] |
| 混合物 | 自动识别准确率上限约 90%，受限于近 identical 谱 | [S12] |
| 制样 | 压片质量、颗粒度、含水均改变谱形 | [S13][S14] |
| 信噪比 | S/N < 3 的峰不可用于定性 | [S5] |
| 导数相关 | 求导放大高频噪声，低信噪比时 r′ 会虚低；二阶导尤甚 | [S20] |

完整 20 条文献（含 ASTM E1252、ASTM E2310、Ph. Eur. 2.2.24、USP <854>、NIST WebBook、SDBS 等）见 [REFERENCES.md](REFERENCES.md)，每条标注其支撑的具体设计决定。

## 已知限制

- **不判晶型**：结晶度低的样品与无定形样品均表现为宽峰，晶型需 XRD。
- **不判分子量与连接方式**：需 MS 与 NMR。
- **不做定量**：面积比为半定量，仅供同批次趋势比较。
- **无谱库检索**：公开检索接口不能按谱图相似度匹配，本工具只给关键词线索（见 [REFERENCES.md](REFERENCES.md)）。
- **混合物**：多组分重叠时，单组分归属可靠性显著下降。
- **位移校正只处理整体平移**：若两谱存在非线性拉伸（不同光栅刻度），校正后会残留系统性残差，此时应重测而非继续比对。
- **肩峰检测有下限**：半高宽比只能发现高度接近或超过半高的组分（约主峰的 60%）；更弱的肩峰需 `deconv` 分峰。
- **宽包不参与峰位判定**：FWHM > 100 cm⁻¹ 的包络峰顶由基线决定，不用于计算峰位偏差。
- **ATR 未做数值校正**：仅提示，不实现 Kramers–Kronig 或色散校正。

## 验证

`ftir-tool/tests/test_synthetic.py` 用已知答案的合成谱做回归测试，18 项，约 20 秒：

```
cd ftir-tool && python tests/test_synthetic.py
```

覆盖三类：

1. **数值原语**：%T 与吸光度往返一致、行序无关、抛物线插值精度、对称峰不对称度约为 1、导数相关对常数偏移免疫
2. **位移估计**：已知位移 ±3 / ±5 / ±8 cm⁻¹ 全部回收；±1 cm⁻¹ 不触发校正；无关谱判「不可靠」不强行对齐
3. **判定不翻转**：同一物质加噪声、加斜基线、改强度、改文件格式与行序后仍判「一致」；平移 3 cm⁻¹ 判「需复核」；无关谱判「不一致」

测试只断言结论，不断言数字末位。三处已知边界也写成了测试：35% 肩峰不可检出、宽包峰位不参与判定、单条弱峰共现不足以判定为一致。

此设计已在开发中抓到两个真实缺陷：吸光度文件被误按透射率裁剪（0.02 的基线被抬到 0.5），以及宽包峰顶漂移被误判为峰位偏移 9 cm⁻¹。

## 版本策略

语义化版本：修复 → patch，新增工具 → minor，接口变更 → major。每次发布打 tag 并记入 [CHANGELOG.md](CHANGELOG.md)。

- 本地补丁方式加载插件：`git pull && npm run build`，重启后生效
- npm 安装：旧版不会被自动替换，需重新指定版本安装
- 修改 `ftir-tool/ftir.py` 后必须同步 `dsh-ftir-plugin/assets/ftir.py`，否则插件仍运行旧引擎
