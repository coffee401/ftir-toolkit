# ftir-tool

[**English**](README.en.md) | 中文

给**不需要红外专业知识、只想要结论**的人用的 FT-IR 分析工具。
零参数即可出结果，输出中文报告 + 图 + CSV。

不依赖任何外部仓库，只用 numpy / scipy / matplotlib。

## 安装

已经建好 `.venv`，无需再装。换电脑重装：

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 三个基础命令（日常就用这三个）

### `check` —— 这张谱能不能用

```
ftir.bat check 1.txt
```

先回答最要紧的问题：谱图有没有问题。检查四项：

- **饱和**：透射率低于 5% 或出现平头峰 → 判"不可用"，建议稀释重测
- **信噪比**：低于 3 → 弱峰不可作为定性依据（GB/T 6040-2019）
- **宽包**：3400 cm⁻¹ 出现 FWHM ≥ 120 的宽包 → 提示可能吸潮或强氢键，建议干燥复测
- **CO₂**：2340 cm⁻¹ 出现双峰 → 提示背景残留

给出三档结论：**合格 / 需注意 / 不可用**。

### `read` —— 一键解谱

```
ftir.bat read 1.txt
```

输出峰表（峰位 / 强度 / 峰形 / FWHM / 参考归属）和一段可直接写进报告的结论，例如：

> 3300-2500 cm⁻¹ 出现宽钝吸收（FWHM 210 cm⁻¹），属羧酸 O-H 伸缩；1688 cm⁻¹ 处出现强吸收，峰形尖锐，符合羧酸 C=O 伸缩振动；1600 与 1580 cm⁻¹ 成对出现芳环骨架振动，且 710 cm⁻¹ 有单取代面外弯曲。
>
> 综合判断：样品含羧酸基、芳环结构。

（以上为示例输出，非真实样品数据。）

并自动附一句局限说明（红外不能定晶型、不能定分子量）。

### `match` —— 和对照谱比对

```
ftir.bat match 样品.txt 对照.txt
```

输出**判定结果**（一致 / 需复核 / 不一致），而不是让人自己看数字：

```
判定：不一致

· 全谱相关系数 r = 0.8933（阈值 0.98）
· 指纹区（≤1500）r = 0.9050
· 峰位最大偏差 12 cm⁻¹（限值 ±5）
· 匹配峰 20 个，未匹配 11 个
· 主要差异区：
    1534 cm⁻¹  对照更强（ΔA -0.473）
    1650 cm⁻¹  样品更强（ΔA +0.460）
```

判定规则（可用 `--threshold` 调整）：

| 条件 | 判定 |
|---|---|
| r ≥ 阈值 且峰位偏差 ≤ 5 且无强差异区 | 一致 |
| r ≥ 0.95 且峰位偏差 ≤ 10 | 需复核 |
| 其他 | 不一致 |

> 相关系数阈值 0.98 是经验值；正式检验应按中国药典 0402 要求预设阈值并做专属性验证。峰位偏差 ±5 cm⁻¹ 引自药典。

## 五个进阶命令（做研究时才用）

| 命令 | 用途 |
|---|---|
| `single` | 单谱峰表 + 标注图（不生成结论文字） |
| `compare` | 多样品峰位对照表 + 相似度矩阵 + 叠加图 |
| `detail` | O-H 重心/FWHM、C=O 二阶导峰位、COO⁻ Δν、面积比 |
| `series` | detail 指标 + 随参数（如离子半径）的趋势与检验 |
| `deconv` | 重叠带分峰拟合（伪 Voigt，输出组分占比、R²） |

### 参考谱扣除（所有命令通用）

```
ftir.bat detail 2.txt --subtract blank.txt --sub-factor auto
```

`auto` 用最小二乘自动定标，适合扣 KBr 空白水峰、大气水汽、CO₂。
**扣过头会出现负峰**，此时改用固定值逐步试（如 `--sub-factor 0.8`）。

### 分峰拟合

```
ftir.bat deconv 1.txt --region 1500,1750
ftir.bat deconv 5.txt --region 1490,1750 --centers 1510,1528,1563,1596,1657
```

判据：拟合出的 FWHM 超过 60 cm⁻¹ 通常说明合峰了，用 `--centers` 手动拆。

## 参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `--outdir` | 输出目录 | `output` |
| `--smooth` | Savitzky-Golay 平滑窗口（奇数） | 9 |
| `--labels` | 样品名，逗号分隔 | 文件名 |
| `--peaks` | read / single 输出峰数 | 10 / 20 |
| `--subtract` | 扣减的参考谱 | 不扣 |
| `--sub-factor` | 扣减比例，数字或 `auto` | `1.0` |
| `--threshold` | match 的相关系数阈值 | 0.98 |

## 支持的输入

两列文本（`.txt` / `.csv` / `.tsv`），第一列波数、第二列强度。
带 `##` 仪器头可直接读，自动识别 `%T` 或吸光度，透射谱自动转吸光度。

## 方法说明

- **基线**：非对称最小二乘（ALS，λ=1e5，p=0.001，12 次迭代）
- **平滑**：Savitzky-Golay 9 点 3 阶
- **挑峰**：find_peaks，prominence 阈值滤噪；窗口内挑峰以捕获肩峰
- **二阶导数**：SG 15 点 3 阶二次导数取负，用于定位重叠组分
- **归属**：按基团频率区间匹配，输出"参考归属"而非唯一答案（共轭与氢键会使峰位漂移）
- **半定量**：以 844 cm⁻¹ 苯环面外弯曲为内参
- **分峰**：伪 Voigt（η 共享），峰位约束 ±25 cm⁻¹，FWHM 4-120 cm⁻¹
- **判定**：相关系数 + 峰位偏差 + 差异区强度三重条件，缺一不可

## 已知局限（工具会主动提示）

- 红外不能判定晶态/非晶态：纳米晶与无定形都表现为宽峰，需 XRD 区分
- KBr 吸潮会显著增强 3400 cm⁻¹ 宽峰，比较含水量前应先干燥
- 弱峰（信噪比 < 3）不能作为定性依据
- 半定量比值只能同批次趋势比较，不能当绝对含量
- ATR 谱与透射谱不可直接比对
